# SNMUN Next.js website application

Part of the parent ZIP development package. Use the parent README-START-HERE.md first.

Run: `npm install`, `npm run dev` (Node.js >= 22). Then open http://localhost:3000.

This is a first foundation with a static institutional homepage, About page, Contact page, shared design system, site assets and intentionally closed Management Portal placeholder. It is not the complete CMS described in the master plan. This folder has not been production deployed or connected to Supabase.

- Website assets: public/assets/
- Brand variables: src/lib/brand.ts
- Global styles: src/app/globals.css
- Homepage: src/app/page.tsx
- Management placeholder: src/app/admin/page.tsx

No public/user accounts. Unconfirmed 2027 annual session remains unpublished. All future confidential data must be stored only after approved security controls are implemented.
